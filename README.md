 # Mutanafas (مُتَنَفَّس)

## Overview

Mutanafas is a mobile application designed to support users' psychological comfort and daily well-being through a combination of relaxation techniques and spiritual activities. The application provides a calm and organized environment that helps users build positive habits, practice mindfulness, and track their daily progress.


## Features<img width="1080" height="2340" alt="Screenshot_1783804323" src="https://github.com/user-attachments/assets/7e84865c-181c-4772-84d8-a7b12449533d" />


* **Daily Worship Checklist**

  * Helps users track their daily worship activities and mark completed tasks.

* **Azkar Section**

  * Provides daily Azkar content, including morning Azkar and religious reminders.

* **Journaling**

  * Allows users to write and save their thoughts and feelings through personal entries.

* **Breathing Exercises**

  * Provides guided breathing sessions to help users relax, reduce stress, and improve focus.

* **Achievements & Statistics**

  * Enables users to monitor their progress and view completed activities through statistics.

* **Light & Dark Mode**

  * Supports both light and dark themes for a comfortable user experience.

## Technologies Used

* **Flutter & Dart**
  Used to develop the cross-platform mobile application.

* **Riverpod**
  Used for state management and efficient application data handling.

* **SQLite (Sqflite)**
  Used for local database storage and managing application data.

* **Material Design**
  Used to create a clean and user-friendly interface.

## Application Screens

The application includes **7 main screens** designed to provide users with a calm and organized experience:

1. **Welcome Screen**

   * Displays the application logo and a welcoming message to introduce users to Mutanafas.

2. **Home Screen**

   * Provides a peaceful greeting and access to the main sections:

     * Worship
     * Journaling
     * Breathing Exercises
     * Statistics
   * Supports both **Light Mode and Dark Mode**.

3. **Journaling Screen**

   * Allows users to write and save their thoughts and feelings through personal entries.

4. **Azkar Screen**

   * Provides daily Azkar content, including morning Azkar and religious reminders.

5. **Daily Worship Screen**

   * Enables users to track daily worship activities through a checklist system and mark completed tasks.

6. **Achievements & Statistics Screen**

   * Displays users' daily progress, completion rate, completed activities, and personal statistics.

7. **Breathing Exercises Screen**

   * Provides different breathing sessions to help users practice calm breathing, reduce stress, and improve focus.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/safa9x/mutanafas.git
```

2. Navigate to the project directory:

```bash
cd mutanafas
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## Project Purpose

The goal of Mutanafas is to provide a supportive digital space that encourages users to maintain positive daily routines, practice relaxation exercises, and improve their overall sense of comfort and well-being.
